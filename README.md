# Pulse — Scrum & Workforce Intelligence Platform

> **Pulse** turns team activity into financial clarity. It is an all-in-one workforce intelligence platform that combines agile Scrum/Kanban management, real-time workload burnout prevention, and live man-hour cost monetization.

---

## ⚡ Features & Capabilities

- **📋 Dual Methodology Engine**: Switch seamlessly between **Time-Boxed Sprints (Scrum)** with SVG ideal-vs-actual burndown curves and **Continuous Flow (Kanban Stream)** without artificial sprint deadlines.
- **📊 Table Spreadsheet View & Kanban Board**: High-efficiency board with WIP capacity limits, multi-tag filtering, and bulk operations.
- **🏷️ Custom Tagging & Label System**: Categorize tickets with color-coded tags (`Frontend`, `Backend`, `Design`, `Marketing`, `Bug`, `Research`, or custom tags).
- **🔋 Workforce Health & Burnout Intelligence**: Automated battery utilization gauges (`Available`, `Healthy`, `High Load`, `Fully Utilized`) and **1-Click Smart Workload Rebalancing**.
- **💰 Financial Cost Tracking**: Real-time man-hour monetization based on custom role billable rates ($/hr), isolated to Platform Administrators (`UN`/`ASG`).
- **🔗 Interactive Dependency Flow Map**: Visual prerequisite tree diagrams showing blocker prerequisites and dependent downstream tickets.
- **🎥 Meeting Action Item Converter**: Log 15-minute quick syncs and automatically convert meeting notes (`@assignee`) directly into tracked Kanban tickets.
- **🎨 1-Click Theme Switcher**: Toggle between **Obsidian Cyber**, **Nordic Light**, and **Midnight Nebula** themes.
- **🔒 Data Sovereignty & Portability**: 1-Click JSON workspace backup export/restore and CSV report generation.

## 🛠️ Local Development & Setup

Pulse is built as an ultra-fast, zero-dependency Single-Page Application (SPA).

1. Clone the repository:
   ```bash
   git clone https://github.com/anantkumarrathod-dev/pulse.git
   ```
2. Open `index.html` in any web browser (Chrome, Edge, Firefox, Safari).
3. No build tools or server setup required!
